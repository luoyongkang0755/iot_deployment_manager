## 二、删除 URDF 中不需要的元素

### 从 scout_mini.urdf 中删除:
1. **`gazebo_ros_control` 插件** — ROS 1 风格 controller，与 gz-sim diff-drive 插件冲突
2. **`laser_link` + `laser_joint`** — 顶部单点激光，由自定义前后双激光雷达替代
3. **4 个 `transmission` 块** — ROS 1 ros_control 概念，Ignition Gazebo 不需要

### 保留的元素
- `camera_link` + `camera_joint` — 保留未删除
- `inertial_link` — 惯性基准

## 三、旋转轴方向修复（多次迭代）

### 问题表现
- 初始: J 键右转（应为左转）
- 第二次修改后: 前进变成后退
- 第三次修改后: J 变成右转
- 解决后: 前进方向对，J 左转对

### 根因分析
URDF 中左轮 `rpy="-1.57"`、右轮 `rpy="1.57"`，导致关节坐标系旋转方向不同。  
`axis="0 0 -1"` 在不同的 rpy 下产生不同的 base_link 系轴方向。

### 最终正确配置
| 关节 | rpy | axis (关节系) | base_link 系轴 |
|------|-----|--------------|---------------|
| front_left_wheel | -1.57 0 0 | `0 0 -1` | **-Y** |
| rear_left_wheel | -1.57 0 0 | `0 0 -1` | **-Y** |
| front_right_wheel | 1.57 0 0 | `0 0 1` | **-Y** |
| rear_right_wheel | 1.57 0 0 | `0 0 1` | **-Y** |

DiffDrive 插件配置:
- `left_joint`: front_left_wheel + rear_left_wheel
- `right_joint`: front_right_wheel + rear_right_wheel
- `wheel_separation`: -0.416503 (即 `-${track}`)

### 教训
- 左右轮 rpy 不同时，axis 也要相应调整使物理轴方向一致
- 轴方向统一 + wheel_separation 符号需要联动调整
- 滑移转向 (skid steering) 和自旋 (pure rotation) 在物理感受上差异极大

## 四、xacro 语法错误

### 错误 1: `$-${track}` 无效语法
- `$-${track}` 被解析为无效数值，导致转弯计算用垃圾值
- 正确写法: `-${track}`

### 错误 2: `<wheel_separation-${track}` 缺少 `>` 
- 编辑时不小心把 `>` 删掉了，变成 `<wheel_separation-${track}</wheel_separation>`
- XML 解析报错: "not well-formed (invalid token)"
- 正确写法: `<wheel_separation>-${track}</wheel_separation>`

## 六、转弯速率慢问题

### 根因: 横向摩擦 (mu2) 太大
- **原因**: 轴方向正确后，转弯是滑移转向 (skid steer)，轮子需要横向滑动
- **mu2=0.9** 时: 横向阻力 ~55 Nm，轮子打滑-抓地循环，不匀速且极慢
- **mu2=0.1** 时: 阻力 ~6 Nm，转弯正常但前进漂移
- **最终 mu2=0.2**: 平衡点，阻力 ~12 Nm，转弯顺畅且前进不漂

### 参数来源
- 碰撞体被 `colcon build` 还原成 mesh 也导致了不匀速
- wheel_radius 在 `scout_diff_drive_controller.py` 中误设为 `0.1009998`（实际是 offset），改为 `0.08`
